Autogroup

When a tab's address or title changes, the first matching rule moves it into the tab group with that name, in whichever window the group is in. If no such group is open, one is created in the tab's current window.

Rules

Domain includes subdomains (youtube.com also matches www.youtube.com). Pattern is a case-insensitive regular expression, e.g. asmr|white noise. Leave either blank to match anything.
